# Portfolio - M. Shri Lakshmi

Portfolio site built with React, TypeScript, Vite and Tailwind CSS. A chibi character follows the cursor, drawn from pre-rendered frames on a canvas.

Run: `npm install --no-package-lock`, then `npm run dev`. Build with `npm run build`.
(package.json pins pnpm; a pnpm-lock.yaml is included, but npm install works too.)
